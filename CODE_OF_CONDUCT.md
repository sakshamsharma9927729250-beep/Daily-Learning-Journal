# Code of Conduct

## Our Commitment

We are committed to maintaining a respectful, inclusive, and professional learning environment.

Everyone contributing to this repository is expected to communicate respectfully and constructively.

## Expected Behavior

- Be respectful and professional.
- Welcome people with different backgrounds and experience levels.
- Give constructive feedback.
- Focus on learning, collaboration, and improvement.
- Respect other contributors' ideas and work.
- Keep discussions relevant to the project.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Trolling or intentionally disruptive behavior.
- Offensive or inappropriate comments.
- Publishing someone's private information without permission.
- Any behavior that creates an unsafe or hostile environment.

## Contributions

Contributors should make a genuine effort to improve the project and follow the repository's contribution guidelines.

When submitting code, documentation, or other changes, please provide clear and meaningful commit messages and descriptions.

## Reporting Issues

If you experience or observe unacceptable behavior, please report it privately to the project maintainer rather than starting a public conflict.

## Enforcement

Project maintainers may remove comments, reject contributions, or take other appropriate action when this Code of Conduct is violated.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, discussions, commits, and other project-related interactions.

## Acknowledgement

By participating in this project, contributors agree to follow this Code of Conduct and help maintain a respectful and productive community.
